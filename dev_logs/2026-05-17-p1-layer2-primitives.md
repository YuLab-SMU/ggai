## Findings / decisions

- **NAMESPACE is hand-managed in this repo.** `devtools::document()` regenerates `man/*.Rd` but leaves `NAMESPACE` alone — no `# Generated by roxygen2` marker at the top. Had to add `export(...)` / `S3method(...)` lines manually. Worth flagging in `AGENTS.md` later, or alternatively switching to roxygen-managed NAMESPACE in a follow-up.
- **Engine detection priority matters.** Composite (patchwork) must be checked before ggplot because patchwork objects also inherit `gg`/`ggplot` in newer versions. Final order: composite → ggplot → complex_heatmap → htmlwidget → grid → base (via device) → unknown.
- **`recordPlot()` displaylist shape varies by R version.** Some R versions stash the display list in `recorded$displaylist`, others in `recorded[[1]]`. `record_has_content()` handles both. Confirmed working on the local R version (`length(dl) > 1` for `plot(1:10)`).
- **`pdf(NULL) + dev.control(displaylist = "enable")`** is the right way to capture base-graphics drawing without producing visible output. It also doesn't interfere with returning ggplot objects from the evaluated code.
- **Inspection is best-effort.** `safe_call()` wrapper means any inspector helper that fails silently returns `NULL` rather than aborting `ggai_inspect_artifact()`. Agents and skills handle the missing-field case, not the throw.
- **Code-as-canonical pays off immediately.** `ggai_render_artifact()` with `force_reexecute = TRUE` or when `object` is `NULL` re-runs the code from scratch — the test `ggai_render_artifact re-executes when object cache is missing` confirms a stub artifact with only `code` set can produce a real rendered figure.

### `devtools::check()` result

Ran after the primitives landed. Result: **1 ERROR, 2 WARNINGS, 1 NOTE**. Categorized:

**Introduced by P1 (fixed in this session):**
- `WARNING — checking dependencies in R code`: `ragg` / `svglite` used via `requireNamespace()` in `R/render.R` but not declared. **Fix:** added both to `DESCRIPTION` `Suggests:`. Re-run of the three P1 test files still passes after the fix.

**Pre-existing, unrelated to P1 (logged as follow-ups, not blocking):**
- `ERROR — test-domain-template-cases.R`: tries to `source("../../docs/assets/cases/single-cell-spatial-template/template_cases.R")` at top level, outside any `test_that()`. `docs/` is in `.Rbuildignore`, so the fixture is unavailable in the installed package and the test errors at load time. Should be either gated behind `skip_if_not(file.exists(...))` or moved to `tests/testthat/_fixtures/`. Filed as TODO.
- `WARNING — non-ASCII characters in R/ggai_entry.R`: pre-existing UTF-8 in error messages / docstrings. Either escape with `\\uxxxx` or drop the non-ASCII content. Filed as TODO.
- `NOTE — hidden files and directories: .aisdk`: a local memory store directory got included in the source root. Should be added to `.Rbuildignore`. Filed as TODO.

The `test_dir()` run earlier showed 468 PASS because `devtools::load_all()` + `test_dir()` runs with `setwd(tests/testthat)` and the path `../../docs/...` resolves at the repo root (where `docs/` does exist). Under `R CMD check` the package is installed into a temp tree and the path is broken. This is a longstanding fragility, not new.
