# ggai Hero Demo

## Purpose

This is the single most important presentation demo:

Use `ggai` to generate a figure that explains **what `ggai` is**.

It is the best way to make the audience understand that:

- `ggai` is not just an image prompt wrapper
- `ggai` is a scientific figure compiler
- `ggai` turns intent into structured prompting, candidate generation, and final figure selection

## Script

Run:

```bash
Rscript demo/direct_ggai_hero_demo.R
```

Outputs:

- `demo_outputs/direct_ggai_hero_best.*`
- `demo_outputs/direct_ggai_hero_prompt.json`
- `demo_outputs/direct_ggai_hero_candidates.json`

## How To Use In The Talk

Open with this image before showing any biomedical figure.

Say:

> “Before I show what ggai can generate, I want to show you what ggai thinks it is.  
> This image itself is generated by ggai.  
> It shows the pipeline from scientific intent, to prompt compilation, to candidate generation, to final figure selection.”

Then explain:

- left = human intent
- middle = compiler / prompt bundle / generation engine
- right = candidate figures and final selected output

## Why It Matters

This image compresses the product thesis into a single visual:

- scientific intent in
- figures out
- with a system, not a one-shot prompt
