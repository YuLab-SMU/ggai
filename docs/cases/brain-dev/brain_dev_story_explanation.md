# 从复制车间到通信网络

这张图是脑发育案例的高级解释图，不是统计图的美化版。

## 叙事对应关系

1. 资料室和样本灯对应真实数据与小样本设计。
2. 抖动的测量雨和被压稳的圆环，对应 limma + empirical Bayes 在 n=2 每组时的方差稳定。
3. 复制车间对应 NSC 一侧的 cell cycle、DNA replication、chromosome segregation。
4. 转折通道对应细胞命运从增殖走向延伸与连接。
5. 通信网络对应 Neuron 一侧的 synapse assembly、postsynapse organization、synaptic vesicle cycle、neurotransmitter transport。

## 这张图的作用

它把统计学原理、统计结果和生物学发现绑成一条可叙述的主线，让读者先理解变化方向，再回头看原始统计图。
