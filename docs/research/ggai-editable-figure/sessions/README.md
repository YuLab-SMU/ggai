# Session Notes

Use this folder for session-specific exploration logs.

## Naming

Use filenames like:

- `YYYY-MM-DD-main-topic.md`
- `YYYY-MM-DD-stream-a-object-model.md`
- `YYYY-MM-DD-stream-b-runtime.md`

## Rules

- session files are append-oriented
- do not overwrite another session's raw notes unless you are explicitly merging them
- stable conclusions belong in the parent folder documents, not only here
- unresolved contradictions should stay visible here until they are synthesized

## Suggested Session Template

Each session file should usually contain:

- goal
- files explored
- findings
- rejected ideas
- new questions
- updates needed in stable docs
